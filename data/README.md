# AI security incidents

`ai-security-incidents.json` feeds the banner and the incident log at https://dataautomation.com/ai-security/. It is refreshed daily.

Format: `updated` (YYYY-MM-DD), `stats` (IBM Cost of a Data Breach figures), and `incidents`, newest first, each with `date`, `title`, `summary` (our own words), `source`, and `url` (the original report).
